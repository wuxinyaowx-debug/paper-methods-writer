# 六类要素抽取清单

按本清单逐类扫描全部材料。每条要素登记：名称、取值（含单位）、作用对象、来源（文件 + 定位）、置信状态（直接写明 / 推断 / 冲突 / 缺失）。

## 1. 方法步骤

- [ ] 整体流程的 ordered steps：每步的**输入、操作、输出、判断条件**；
- [ ] 预处理 / 后处理步骤是否单列，而非并入一句"按标准流程处理"；
- [ ] 每步对应的代码入口（脚本、函数、命令）；
- [ ] 步骤间的依赖与中间产物（文件、检查点）。

常见来源：`train.py` / `run.sh` / `Makefile` / `main.py` 的 `main()`、README 的 Usage 一节、论文方法节。

## 2. 实验设置

按**训练、验证、测试**三列分别核对，不得合并描述：

- [ ] 硬件：GPU/CPU 型号与数量、内存；
- [ ] 软件：操作系统、CUDA/cuDNN、框架及版本（PyTorch/TF 等）、关键库版本；
- [ ] 运行环境：容器镜像、虚拟环境、依赖锁定文件（`requirements.txt`、`environment.yml`、`Dockerfile`）；
- [ ] 随机种子及设置位置（代码 / 配置）；
- [ ] 重复次数与统计方式（均值±方差、取最优等）；
- [ ] 训练时长 / 吞吐等运行成本（日志中的时间戳差值）。

常见来源：`requirements.txt`、`environment.yml`、`Dockerfile`、日志头部、论文的 Implementation Details、Slurm/作业脚本。

## 3. 参数与来源

为每个参数登记一行：名称 | 取值 | 单位 | 作用对象 | 来源文件 | 定位（配置键路径 / 行号 / 页码） | 状态。

- [ ] 模型结构参数（层数、宽度、参数量）；
- [ ] 优化参数（优化器、学习率及调度、batch size、epoch/steps、权重衰减、梯度裁剪）；
- [ ] 损失函数与权重系数；
- [ ] 数据相关参数（裁剪尺寸、归一化常数、增强概率）；
- [ ] 评测参数（阈值、top-k、指标实现版本）；
- [ ] **正文数值 = 配置取值**：论文叙述、配置文件、命令行参数、日志回显四处取值交叉核对，不一致即记冲突。

常见来源：`config.yaml` / `config.json` / `argparse` 默认值、训练日志开头的 hyperparameter dump、论文表格。

## 4. 数据集与划分

- [ ] 名称与**版本**（含下载地址或获取方式）；
- [ ] 规模：样本数、类别数、输入维度；
- [ ] 预处理与增强；
- [ ] 划分比例与**随机方式**（官方划分 / 随机种子 / 分层策略）；
- [ ] 各子集用途（train/val/test 分别用于什么）；
- [ ] 许可与使用限制（若材料给出）。

## 5. 对照实验

- [ ] 每个基线的名称、版本 / 出处、是否复现还是引用原论文数值；
- [ ] 对照是否**同预算**（相同数据划分、训练步数、超参搜索量、硬件）；
- [ ] 评价指标定义与实现（官方脚本 / 自实现）、统计方式（多次运行均值、置信区间、显著性检验）；
- [ ] 消融实验的变量控制：每次只改一个因素。

## 6. 可复现性与限制

- [ ] 复现清单：代码版本（commit/tag）、环境、完整命令、数据获取方式、预训练权重来源；
- [ ] 运行成本估计；
- [ ] 限制条件：写到**具体失效场景**（如"输入长度超过 X 时显存溢出""类别极度不平衡时指标 Y 失真"），禁止"本文方法存在一定局限"式套话；
- [ ] 适用范围：方法适用的数据模态、规模、硬件门槛。

## 冲突与缺失登记规则

| 状态 | 判定 | 正文处理 |
|-|-|-|
| 直接写明 | 单一来源、含义明确 | 直接陈述 + 来源标注 |
| 推断 | 多处材料组合得出 | 写明"由 X 与 Y 推得" |
| 冲突 | 多处材料取值不一致 | 并列全部取值与来源，标 `〔待确认: 冲突〕` |
| 缺失 | 材料中不存在 | 写 `〔待确认: …〕`，入缺口报告 |
